CIP4 xJdfLib

xJdfLib is a Java library for creating, reading, validating and packaging XJDF (JDF 2.0) and XJMF documents.

XJDF no longer models an entire job as one large ticket. Each XJDF document describes a single transaction between two applications, and a job is modeled as one or more transactions. An XJMF message is the envelope used to exchange commands, queries and signals between those applications.

Getting Started

Set the global agent constants once at application start. They are used to create default headers and audit entries: 

{@code
XJdfConstants.AGENT_NAME = "PreviewService";
XJdfConstants.AGENT_VERSION = "1.2.34";
XJdfConstants.DEVICE_ID = "PREVIEW_SERVICE";
}

Create an XJDF document, add a resource set and serialize it: 

{@code
XJdfDocument document = new XJdfDocument("42", "Interpreting", "Rendering");
ResourceSet previews = document.addResourceSet(Preview.class, ResourceSet.Usage.INPUT);
document.addSpecificResource(previews, new Preview()
    .withPreviewFileType(Preview.PreviewFileType.PNG)
    .withFileSpec(new FileSpec().withURL(new URI("preview.png"))));
byte[] xml = document.toXml();
}

Create and parse XJMF messages with {@link org.cip4.lib.xjdf.XJmfMessage}, bundle an XJDF document with its referenced files with {@link org.cip4.lib.xjdf.XJdfZipPackage}, and bundle messages, XJDF documents and referenced files with {@link org.cip4.lib.xjdf.XJmfZipPackage}.

Package Guide

  • {@link org.cip4.lib.xjdf} - entry points for documents, messages and packages.
  • {@link org.cip4.lib.xjdf.type} - immutable value objects for the XJDF data types.
  • {@link org.cip4.lib.xjdf.xml} - XML parsing, serialization and schema validation.
  • {@link org.cip4.lib.xjdf.validator} - the element validator framework.
  • {@link org.cip4.lib.xjdf.util} - helpers for headers, identifiers, resources, partitions and unit conversion.
  • {@link org.cip4.lib.xjdf.exception} - checked exceptions thrown by xJdfLib.
  • {@link org.cip4.lib.xjdf.schema} - JAXB classes generated from the official CIP4 XJDF schema.

Conventions

  • All lengths are expressed in points, as required by XJDF.
  • Numeric XML values are written with the US locale and a fixed number of decimals.
  • The classes in {@link org.cip4.lib.xjdf.type} are immutable and thread-safe.
  • {@link org.cip4.lib.xjdf.XJdfConstants} is global mutable state and must be initialized before creating documents or messages.
